# Continuidad y trabajo activo

Plantilla de router operativo: enlazar la memoria general y los expedientes activos
existentes. No mantener un catálogo histórico acumulativo.

Para retomar, consultar memoria general existente, elegir el trabajo y leer su
resumen o registro compacto. Un mínimo directo no requiere este router ni memoria.
El runtime de trabajo permite consultar estados; este router no duplica cada tarea,
fecha o revisión del estado estructurado.

La evidencia temporal no es autoridad del sistema. Al cerrar, promover conocimiento
significativo a fuentes permanentes y retirar entradas activas existentes; no crear
documentos ni actualizaciones por casilla.
