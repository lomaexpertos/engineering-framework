# Resultado de alto nivel

Plantilla: nombrar una capacidad o resultado verificable, no una lista de archivos.
Registrar estado real, prioridad y owner únicamente cuando se conozcan.

## Resultado y motivo

¿Qué cambiará para los usuarios o para la operación y por qué importa?

## Alcance y dependencias

¿Qué capacidades comprende y qué condiciones externas determinan su avance?

## Avance real y siguiente paso

¿Qué resultado ya está entregado y qué falta? Distinguir resultado validado de
resultado disponible en un ambiente. No inventar porcentajes ni enlazar evidencia
necesaria para comprender el avance permanente.
