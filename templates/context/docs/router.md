# Conocimiento del proyecto

Plantilla de router: conservar solo entradas con contenido real y convertir sus
rutas en enlaces válidos al adaptar. No describe el estado de ningún producto.

| Necesidad de consulta | Fuente canónica a enlazar |
| --- | --- |
| Entender propósito, usuarios y lenguaje | Producto |
| Entender límites y dependencias compartidas | Sistema |
| Cambiar una regla o flujo concreto | Dominio afectado |
| Comprender una decisión y sus consecuencias | Decisión vigente |
| Identificar qué no puede romperse | Fuente de la invariante |
| Conocer prioridades y resultados esperados | Roadmap |

Un tema tiene una sola autoridad. No enlazar expedientes temporales ni convertir
este router en un catálogo de tareas o en otra explicación del sistema.
