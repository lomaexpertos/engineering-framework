# Consumer project template

Base de referencia para la integración de un repositorio consumidor. El sincronizador
común a la instalación asistida y al workflow central opcional copia Policies y Skills
sin distribuir documentación sobre su operación.

[`AGENTS.md`](AGENTS.md) es el router inicial sugerido.
`engineering/docs/`, `engineering/specs/` y `engineering/quality-review/` son
namespaces propiedad del proyecto y se crean solo cuando exista contenido real. El
contenido de `engineering/corporate/` y las Skills se genera desde la fuente; no se
mantiene manualmente en esta plantilla.
