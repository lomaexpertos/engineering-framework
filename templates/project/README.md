# Consumer project template

Base contractual para la integración de un repositorio consumidor. El build futuro
combinará esta plantilla con Policies y Skills de una release.

[`AGENTS.md`](AGENTS.md) es el router inicial sugerido.
[`engineering/project/`](engineering/project/README.md) contiene únicamente
documentación propiedad del proyecto. El contenido de `engineering/corporate/`, las
Skills y el manifest se generarán; no se mantienen manualmente en esta plantilla.
