# Environments policies router

Selecciona el ambiente afectado y carga solo su Policy más las reglas compartidas que
correspondan.

| Tarea | Policies |
| --- | --- |
| Operar o estructurar producción | [`production.md`](production.md) |
| Modificar el entorno del desarrollador | [`local.md`](local.md) |
| Crear o destruir un ambiente remoto efímero | [`preview.md`](preview.md) |
| Comparar capacidades entre ambientes | [`parity.md`](parity.md) |

Cuando un cambio afecte varios ambientes, consulta cada Policy aplicable. La existencia
de un ambiente es condicional a las capacidades reales del repositorio.
