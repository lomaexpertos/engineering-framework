# Infrastructure policies router

Consulta este dominio al cambiar infraestructura, configuración, ambientes,
contenedores, despliegues, rollback u observabilidad.

## Enrutamiento planeado

- Recursos reproducibles: `infrastructure-as-code.md`.
- Imágenes y ejecución aislada: `containers.md`.
- Configuración de servicios: `configuration.md`.
- Separación de ambientes: `environments.md`.
- Liberación de cambios: `deployment.md`.
- Reversión y recuperación: `rollback.md`.
- Señales operativas: `observability.md`.
