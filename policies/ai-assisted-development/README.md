# AI-assisted development policies router

Consulta este dominio cuando un agente tome decisiones, modifique código o declare
una tarea terminada.

## Enrutamiento planeado

- Conducta general: `agent-behavior.md`.
- Carga progresiva de conocimiento: `context-management.md`.
- Inspección y reutilización previa: `reuse-before-create.md`.
- Evidencia antes de terminar: `validation-before-completion.md`.
- Actualización de fuentes canónicas: `documentation-maintenance.md`.
