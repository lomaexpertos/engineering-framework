# AI-assisted development policies router

Consulta este dominio cuando un agente tome decisiones, modifique código o declare
una tarea terminada.

## Routing

- Inspección, alcance, causa raíz y conflictos:
  [`agent-behavior.md`](agent-behavior.md).
- Descubrimiento progresivo y separación de conocimiento:
  [`context-management.md`](context-management.md).
- Evaluación, planeación y ejecución de cambios de infraestructura:
  [`infrastructure-change-safety.md`](infrastructure-change-safety.md).
- Creación de componentes, patrones o abstracciones:
  [`reuse-before-create.md`](reuse-before-create.md).
- Evidencia antes de declarar una tarea terminada:
  [`validation-before-completion.md`](validation-before-completion.md).
- Actualización de fuentes documentales canónicas:
  [`documentation-maintenance.md`](documentation-maintenance.md).

No agregar aquí reglas exclusivas de una herramienta o proyecto; esas diferencias se
resuelven en tooling de distribución o documentación local.
