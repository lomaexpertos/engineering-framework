# Reuse before create

## Requirements

1. Antes de crear una pantalla, componente, layout, interacción, abstracción o
   convención, el agente **MUST** inspeccionar implementaciones y documentación
   existentes relacionadas.
2. Una solución existente **MUST** reutilizarse o extenderse cuando satisfaga
   razonablemente la necesidad sin introducir un riesgo mayor.
3. El agente **MUST NOT** reemplazar un patrón consolidado únicamente porque prefiera
   una alternativa más moderna, limpia o familiar.
4. Una solución nueva **MAY** introducirse cuando el usuario la solicite explícitamente
   o ningún patrón existente sea adecuado.
5. Cuando cree un patrón nuevo, el agente **MUST** explicar por qué la reutilización no
   fue suficiente y actualizar la documentación canónica aplicable.
