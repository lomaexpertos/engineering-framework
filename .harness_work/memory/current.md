# Contexto operativo

No quedan iniciativas de desarrollo activas ni trabajadores en ejecución.
La entrega del harness está consolidada en sus fuentes duraderas.

Para orientar trabajo nuevo, consultar [roadmap](../../docs/roadmap/README.md) y
[pendientes de alto nivel](../../docs/roadmap/backlog.md).
El [router de conocimiento](../../docs/README.md) conserva el contexto estable.

Publicar o adoptar una versión en otro proyecto es una operación explícita aparte.
